## Migration rules

1. Preserve the untouched original in a private/source archive.
2. Use human-readable lowercase filenames in the production repository.
3. Strip unnecessary metadata from public derivatives.
4. Produce AVIF first, WebP fallback for photos where practical.
5. Generate at least mobile and desktop widths for large photography.
6. Do not upscale small legacy source images.
7. Prefer a fresh photoshoot for facility/team imagery if the originals no longer represent the current operation.
8. Reverify regulatory marks and product artwork rather than treating this archive as current truth.
